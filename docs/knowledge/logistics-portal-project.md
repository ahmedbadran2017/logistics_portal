**Existing asset:** `~/Preparation/preparation_dashboard_updated_v2.html` — a Frappe-hosted web page (front-end only, `frappe.client.get_list`/`insert`). Order/stock-centric. Covers Ready/Partial/Out → Combined Pick → In Pick List → Cooking → Packing → Ready to Ship. Only write action = create Pick List. Ignores Delivery Note, Shipment, Returns. Company hardcoded "Justyol Morocco", warehouse root "Soft Warehouse - JM".

**Carrier = Cathedis** (Moroccan COD last-mile; AWB `LD...`; `custom_track_shipment_status` synced). Channels: Shopify/YouCan/WordPress/EasyOrders/Manual/Landing Page.

**Team** = Dept `Logistics - JM` (~9 "Logistics Agent"s, uniform title). Roles are emergent from stage touched, not titles: anaskarrassi=Dispatcher(creates PLs), marouane/said/asmaa=Pickers, redazaari47=Packer/Shipper(creates Shipments). See [logistics-erpnext-fields](logistics-erpnext-fields.md).
